# Essanz — Landingpage

Landingpage-Entwurf für die App-Idee „Essanz": eine Gesamtvermögensbilanz
für Portfolio-Performance-Nutzer:innen, inklusive einer eigenen Auswertungsebene
für vermietete Immobilien.

## Inhalt

- `index.html` — vollständig eigenständige, statische Seite (kein Build-Schritt nötig)

## Live schalten mit GitHub Pages

1. Dieses Repo auf GitHub pushen (siehe Anleitung, die Claude dir separat gegeben hat)
2. GitHub → Repo → **Settings → Pages**
3. Unter „Build and deployment" → Source: **Deploy from a branch**
4. Branch: **main**, Ordner: **/ (root)**
5. Speichern — nach ein bis zwei Minuten ist die Seite unter
   `https://<dein-github-name>.github.io/<repo-name>/` erreichbar

## Update

Änderungen an `index.html` committen und pushen — GitHub Pages baut automatisch neu.
